# Product Roadmap

Halo's current foundation is a local Windows productivity assistant backed by stable sample data and a local AI model. The roadmap grows from that foundation while preserving clear user control and local-first defaults.

## Near term

- Add selectable fictional work scenarios so demos can cover onboarding, release planning, incident response, and project coordination without changing the active workspace unexpectedly.
- Improve long-running AI interactions with streaming responses, cancellation, and clearer progress and fallback states.
- Add focused filters and views for tasks, meetings, and engineering work as sample datasets grow.
- Expand automated UI smoke tests to cover the main workflows and desktop packaging.

## Product maturity

- Add user-controlled backup, restore, and export for local tasks and notes.
- Add a clear activity history for user-requested task and note changes, with retention controls.
- Provide a signed installer, release notes, and a predictable update process for Windows builds.
- Improve keyboard navigation, screen-reader labeling, and contrast validation across dashboard and settings controls.
- Add repeatable quality benchmarks for planning and grounded AI responses using synthetic evaluation cases.

## Longer-term options

- Explore optional, user-authorized connections to approved productivity services, with narrowly scoped permissions and a separate security and privacy review before implementation.
- Support additional local model choices with documented hardware requirements and response-quality comparisons.
- Add configurable workspaces so users can separate projects and their sample or personal data.

Roadmap items are proposals, not current capabilities. Halo remains local and sample-data-only unless a future release explicitly adds and documents another data source.
